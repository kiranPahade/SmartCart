# SmartCart — Customer Segmentation Analysis

SmartCart is a customer analytics project built around a simple business question: **how can a business understand its customers beyond total sales?**

In this project, I explored customer data to look for patterns in shopping behaviour and identify groups of customers with similar characteristics. The goal is to turn raw customer information into insights that could help a business think more clearly about customer engagement, marketing, and retention.

## Project notebook and dataset

- **Notebook:** [`smartcart_MBA.ipynb`](./smartcart_MBA.ipynb)
- **Dataset:** [`smartcart_customers.csv`](./smartcart_customers.csv)

## What this project covers

- Exploring the customer dataset and understanding its structure.
- Preparing the data for analysis, including checking for issues that could affect the results.
- Looking for patterns in customer characteristics and spending behaviour.
- Using customer segmentation as a way to make a large customer base easier to understand.
- Interpreting the results from a business point of view rather than treating the analysis as numbers alone.

## Tools

The work is documented in a Jupyter Notebook and uses Python for data analysis. Check the notebook imports for the exact libraries used in this version of the project.

## Getting started

1. Clone this repository:

   ```bash
   git clone https://github.com/kiranPahade/SmartCart.git
   cd SmartCart
   ```

2. Install Jupyter Notebook and the Python libraries imported in the notebook.
3. Open `smartcart_MBA.ipynb` and run the cells in order.
4. Keep `smartcart_customers.csv` in the location expected by the notebook, or update the file path if you store it elsewhere.

## What I learned

This project helped me practise working with customer data, exploring behaviour patterns, and connecting analysis to practical business questions. It also reinforced that segmentation is most useful when the groups can be explained clearly and lead to sensible next steps.

## Notes

The findings depend on the dataset and the approach used in the notebook. Customer segments should be treated as analytical groups, not as fixed descriptions of every individual customer.
